# Meta Removes Facial Recognition from Smart Glasses After EFF Exposes Surveillance Code

**TL;DR:** Meta quietly removed facial recognition code from its smart glasses app after EFF and WIRED exposed the surveillance capability that could identify strangers in public.

## Key Points

- WIRED exposed facial recognition technology embedded in Meta AI companion app for smart glasses
- EFF's Threat Lab verified findings through static analysis of the code
- System could convert face images into biometric signatures to identify strangers publicly
- Meta removed FRT code, recognition alerts, and biometric databases in June 5th app update
- Company removed features within 48 hours of public exposure despite initial defensive stance
- Meta refuses to confirm whether NameTag system will return or what data was collected during testing
- Victory demonstrates need for enforceable privacy laws with private right of action
