# Signal Alumni Launch Encrypted Spaces for Private Collaboration Apps

**TL;DR:** Signal alumni released Encrypted Spaces, an open-source framework for building surveillance-resistant collaboration apps that could replace Slack, Discord, and Google Docs with encrypted alternatives.

## Key Points

- Signal alumni launched Encrypted Spaces, a new open-source project
- Framework enables building private collaboration applications
- Targets features comparable to Slack, Discord, and Google Docs
- Built-in protection against surveillance from ground up
- Open-source model allows community development and auditing
- Could enable decentralized alternatives to mainstream collaboration platforms
- Represents potential shift toward privacy-first workplace tools
