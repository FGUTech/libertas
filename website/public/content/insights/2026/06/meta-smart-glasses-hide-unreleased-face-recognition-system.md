# Meta Smart Glasses Hide Unreleased Face Recognition System

**TL;DR:** Code review reveals Meta embedded unreleased face-recognition system in smart glasses that identifies people using biometric data stored on users' phones.

## Key Points

- WIRED discovered unreleased face-recognition code in Meta's smart glasses platform
- System designed to identify people using biometric data from users' phones
- Feature appears to be built but not publicly announced or activated
- Represents expansion of facial recognition into consumer AR/VR devices
- Raises concerns about ubiquitous biometric surveillance in everyday objects
- Could enable mass identification and tracking without explicit consent
- Highlights need for counter-surveillance tools as AR glasses become mainstream
