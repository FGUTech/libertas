# Access Now Report: Data Privacy as Defense Against Electoral Disinformation in Latin America

**TL;DR:** Access Now analysis shows how mass data collection enables personalized disinformation campaigns and proposes privacy law enforcement as key defense for upcoming Latin American elections.

## Key Points

- Access Now published analysis linking data collection practices to disinformation effectiveness in Latin America
- Report focuses on microtargeting techniques that use personal data for political manipulation
- Identifies AI-generated deepfakes and bots as amplifying disinformation impact through personalized targeting
- Covers upcoming electoral contexts in Argentina, Mexico, Brazil, Colombia, and Peru
- Recommends enforcing data protection laws rather than content moderation as primary defense
- Proposes banning political microtargeting tools during electoral periods
- Calls for cooperation between data protection and electoral authorities to combat coordinated campaigns
