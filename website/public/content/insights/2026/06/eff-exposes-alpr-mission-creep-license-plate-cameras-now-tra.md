# EFF Exposes ALPR Mission Creep: License Plate Cameras Now Track Noise Complaints

**TL;DR:** EFF reports widespread surveillance expansion as automated license plate readers, originally for safety, now track citizens for minor infractions like noise complaints.

## Key Points

- Tens of thousands of ALPR cameras form nationwide surveillance network across US
- Mission creep: systems originally sold for safety now used for noise complaints and minor violations
- EFF documented new examples including school residency verification and background checks
- Meta removed facial recognition code from smart glasses app after public pressure
- EFF testified to Congress about AI surveillance concerns and government overreach
- ALPR networks function as 'universal people-trackers' beyond stated purposes
- Pattern demonstrates how surveillance infrastructure expands once deployed
