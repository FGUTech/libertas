# Microsoft Threatens Legal Action Against Researcher Who Broke BitLocker

**TL;DR:** Anonymous security researcher 'Nightmare Eclipse' published exploits breaking Microsoft BitLocker encryption, prompting Microsoft to threaten legal action against the disclosure.

## Key Points

- Security researcher 'Nightmare Eclipse' published series of Windows exploits
- One exploit reportedly breaks BitLocker disk encryption
- Microsoft threatened legal action against the anonymous researcher
- BitLocker bypass represents significant privacy/surveillance threat
- Legal threats against security researchers raise censorship concerns
- Dispute involves back-and-forth recriminations between parties
- Pattern of corporate intimidation tactics against vulnerability disclosure
